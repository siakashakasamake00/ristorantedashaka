Cambiare il PIN

Per sicurezza il PIN non si cambia da qui, ma su Netlify:

  1. Apri il progetto su Netlify
  2. Project configuration → Environment variables
  3. Modifica ADMIN_PIN (pannello) o KITCHEN_PIN (cucina)
  4. Deploys → Trigger deploy
